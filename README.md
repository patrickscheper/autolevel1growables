# Auto Level 1 Growables
Ensures that all growable buildings placed with mods like [Ploppable RICO Revisited](https://steamcommunity.com/sharedfiles/filedetails/?id=2016920607) or [Plop the Growables](https://steamcommunity.com/sharedfiles/filedetails/?id=924884948) automatically start at Level 1 which allows them to grow naturally based on their surroundings.

Custom assets like growable buildings from the Steam Workshop can sometimes have higher levels when plopped with the above tools. This can lead to:
- Unbalanced gameplay for natural cities
- Missing services / land value issues
- Broken education and workforce demands

This mod ensures that all buildings always start as a Level 1 building and can naturally grow depending on the services around it. 

#Technical Notes:

- The mod checks for new buildings being placed and resets their level to 1 if they're a RICO (Residential, Industrial, Commercial, Office) building.
- Works with all custom RICO assets.
- Lightweight and safe to use with other mods such as [Ploppable RICO Revisited](https://steamcommunity.com/sharedfiles/filedetails/?id=2016920607) or [Plop the Growables](https://steamcommunity.com/sharedfiles/filedetails/?id=924884948) automatically start at Level 1.
- No known incompatibilities.
